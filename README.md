# Dev
1. Clone the project
1. Make a copy of the ```.env``` fie an rename it: ```env.template``` 
3. Execute ```npm install```
4. Exceute ```docker-compose up -d``` to turn on the database image of Docker
5. Execute ```npm run start:dev``` to run the Beckend App
6. Go to the site ```http://localhost:3000/graphql```
